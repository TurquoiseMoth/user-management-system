User Management System - Beginner Explanation

Goal
----
This project is a small React app that manages a list of users.
It uses global state (Redux Toolkit) so all pages can read and update the same user data.
It uses React Router so the app can have multiple pages without reloading the browser.

What the app does
-----------------
- Loads initial users from the public API: https://jsonplaceholder.typicode.com/users
- Stores that user list in Redux state
- Shows a list of users on /users
- Shows details for one user on /users/:id
- Lets you add a user on /add-user
- Lets you edit a user on /edit-user/:id
- Lets you delete a user locally

Important detail
----------------
After the first data load, add/edit/delete happens only in Redux state in the browser.
This means there is no real API call when you add, update, or delete a user.
That is okay for learning and for a local demo app.

Key files and what they do
--------------------------

src/types/user.ts
- Defines the shape of a user object.
- A user has id, name, email, and nested address fields.

src/store/userSlice.ts
- This is the Redux Toolkit slice for user data.
- It contains:
  - initial state: a list of users, a loading flag, and an error message
  - an async thunk fetchUsers() that loads users from the API
  - reducers addUser(), updateUser(), deleteUser()
- Reducers change state in Redux when actions are dispatched.

src/store/store.ts
- Configures the Redux store and connects the user slice.
- Exports RootState and AppDispatch types for TypeScript.

src/main.tsx
- Starts the React app.
- Wraps <App /> with <Provider store={store}> so Redux is available everywhere.

src/App.tsx
- Sets up routes with React Router.
- Uses <BrowserRouter> and <Routes> to connect URLs to pages.
- Contains navigation links for Users and Add User.

src/components/UserList.tsx
- Loads users from Redux using useSelector.
- Dispatches fetchUsers() when the app loads.
- Shows loading and error states.
- Renders a UserCard for each user.

src/components/UserCard.tsx
- Displays the user name, email, and address.
- Has buttons to view details, edit, and delete the user.
- The delete button dispatches deleteUser() to Redux.

src/components/UserForm.tsx
- Reusable form component for adding and editing users.
- Uses local React state for form fields.
- Calls onSubmit() with the user data when submitted.

src/pages/UsersPage.tsx
- Page component for the /users route.
- Shows the list of users by rendering <UserList />.

src/pages/UserDetailsPage.tsx
- Page component for the /users/:id route.
- Reads the URL id and finds the matching user in Redux.
- Shows full user details.

src/pages/AddUserPage.tsx
- Page component for /add-user.
- Renders <UserForm /> and dispatches addUser() on submit.
- Navigates back to /users after adding.

src/pages/EditUserPage.tsx
- Page component for /edit-user/:id.
- Loads the existing user from Redux based on the URL id.
- Prefills <UserForm /> with that user’s data.
- Dispatches updateUser() on submit and navigates back to /users.

How data flows
--------------
1. App starts and shows /users.
2. UserList sees there are no users and dispatches fetchUsers().
3. Redux fetches the list from the API and stores it.
4. UserList reads users from Redux and displays them.
5. Add/Edit pages update Redux directly with addUser/updateUser.
6. Delete button removes a user from Redux.

Why Redux Toolkit?
------------------
- Redux Toolkit is the recommended way to write Redux today.
- It reduces boilerplate code.
- It handles immutable updates safely for us.
- It works well with TypeScript.

Why React Router?
-----------------
- React Router lets the app use different URLs for different screens.
- The browser address bar changes without full page reloads.
- Pages like /add-user and /users/3 become possible.

How to run the app
------------------
1. Open terminal in the project folder.
2. Run: npm install
3. Run: npm run dev
4. Open the browser at the address shown by Vite.

Beginner tips
--------------
- `useSelector()` reads Redux state inside components.
- `useDispatch()` sends actions to Redux.
- A slice file like userSlice.ts defines actions and state logic.
- Routes in App.tsx connect URLs to page components.
- The form component uses `useState()` to store the values typed by the user.
